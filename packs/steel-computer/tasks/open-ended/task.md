# Work request: put the service to full use

You hold a browser automation service and its description file,
`openapi.json`, in this workspace.

1. Read the description and learn what the service can do.
2. Pick the one errand that makes the service do the most for a
   customer. Favor work that chains several capabilities.
3. Carry the errand out end to end.
4. Clean up every resource you create.

Then answer in JSON that matches the open work result schema file in
this workspace:

- `task_chosen`: the errand you picked, in one sentence.
- `operations_used`: every service operation you called.
- `outcome`: what the errand achieved.
- `resources_cleaned_up`: whether you cleaned everything up.

Leave nothing running.
